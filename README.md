# Algorithm Comparison Dashboard

لوحة أكاديمية لمقارنة خوارزميات جدولة العمليات باستخدام Python وStreamlit، دون قاعدة بيانات. يدعم المشروع الإدخال اليدوي، واستيراد CSV، وحساب مؤشرات الأداء، ومخططات Gantt، والمقارنة المرئية.

## الخوارزميات

يطبق النظام FCFS وSJF غير الاستباقية وRound Robin وPriority غير الاستباقية. تُشغّل كل خوارزمية على نسخة مستقلة من نفس العمليات لضمان عدالة المقارنة.

## تنسيق CSV

يجب أن يحتوي الملف على الأعمدة التالية بالإنجليزية وبالأسماء الدقيقة:

| العمود | النوع | القيود |
|---|---|---|
| `process_id` | نص | غير فارغ وغير مكرر |
| `arrival_time` | عدد صحيح | صفر أو أكبر |
| `burst_time` | عدد صحيح | أكبر من صفر |
| `priority` | عدد صحيح | أكبر من صفر |

يمكن تنزيل قالب CSV من داخل التطبيق. مثال موجود في `examples/sample_processes.csv`.

## المخرجات

يعرض التطبيق جدولًا تفصيليًا لكل خوارزمية، ويحسب Completion Time وWaiting Time وTurnaround Time وResponse Time، ثم يعرض متوسطات هذه المقاييس، وعدد تبديلات السياق، ووقت الخمول. كما يرسم مخطط Gantt لكل خوارزمية ورسمًا مقارنًا للمقاييس.

التوصية المعروضة في الواجهة مرتبطة بالمقياس الذي يختاره المستخدم، ولا تدّعي وجود خوارزمية أفضل بصورة مطلقة.

## التشغيل

```bash
cd /home/ubuntu/algorithm_comparison_dashboard
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run main.py
```

```bash
pytest -q
```

## بنية المشروع

| المسار | المسؤولية |
|---|---|
| `core/models.py` | نماذج العمليات وشرائح التنفيذ والنتائج |
| `core/csv_loader.py` | قراءة CSV والتحقق من schema والقيم |
| `core/algorithms.py` | الخوارزميات الأربع ومحرك النتائج |
| `main.py` | واجهة Streamlit والتفاعل والتصور |
| `tests/` | اختبارات الوحدات والحالات الحدية |
| `examples/` | ملف CSV تجريبي |

لا يستخدم المشروع قاعدة بيانات. تبقى البيانات والنتائج في ذاكرة جلسة Streamlit، ويمكن إعادة تحميلها من CSV في أي وقت.
